# Anish Yadav - Personal Brand Website

Official domain: [https://anishyadav.com.np](https://anishyadav.com.np)

## Project Overview
This repository contains the complete production-ready source code for **Anish Yadav's** personal brand website. It focuses on Education, Technology, Artificial Intelligence, Programming, Blogging, and Entertainment, featuring a luxury glassmorphism design language with dark/light mode, smooth scroll animations, interactive particle effects, search popups, and SEO optimizations.

## Folder Structure
```
anishyadav-website/
├── index.html       # Home Page
├── about.html       # About & Timeline Page
├── projects.html    # Portfolio & Projects Showcase
├── blog.html        # Articles & Education Hub
├── contact.html     # Contact Form & Social Links
├── 404.html         # Custom Error Page
├── style.css        # Luxury Glassmorphism Stylesheet
├── script.js       # Interactive JavaScript Engine
├── robots.txt       # Search Engine Instructions
├── sitemap.xml      # XML Sitemap
├── manifest.json    # Progressive Web App Manifest
├── images/          # SVG Vector Assets & Favicons
└── README.md        # Technical Documentation
```

## Tech Stack
- **HTML5**: Semantic tags, accessible landmarks, Schema.org JSON-LD
- **CSS3**: CSS Custom Properties, Glassmorphism, Flexbox, Grid, Keyframe Animations
- **Vanilla JavaScript (ES6)**: Theme switching, Particles canvas, Typing animation, Counter effect, Toast notifications

## Deployment
1. **GitHub Pages**: Simply push this repository to your `main` branch and enable GitHub Pages in Repository Settings -> Pages.
2. **Cloudflare Pages**: Connect your repository to Cloudflare Pages for instant global CDN deployment.
